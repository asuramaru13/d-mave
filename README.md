# D.Mave — лендинг-визитка

Одностраничный статичный сайт-визитка музыканта. Чистый HTML/CSS/JS, без сборки.

## Как открыть
Просто дважды кликните `index.html` — откроется в браузере. Для заливки в интернет
подойдёт любой статик-хостинг (GitHub Pages, Netlify, Cloudflare Pages): загрузите
всю папку как есть.

## Структура
```
index.html     — разметка (здесь меняется весь текстовый контент)
styles.css      — стили и дизайн-токены (цвета/шрифты в начале файла, блок :root)
script.js       — таймер винила, пауза вращения при наведении, аудио-превью треков
dither-veil.js  — ч/б dither-эффект на проигрывателе (hover открывает фото).
                  Классический скрипт: ogl тянется с CDN (нужен интернет),
                  картинка — из player-image.js, поэтому работает и при открытии
                  index.html двойным кликом (file://), и на хостинге.
player-image.js — картинка вертушки, встроенная как data-URI (для dither-эффекта).
gooey-nav.js    — навигация вверху по центру (ARTIST/ABOUT/LAST RELEASE/FOLLOW),
gooey-nav.css     gooey-эффект на WebGL; клик по пункту плавно скроллит к секции.
photos/
  dreamer player.png   — вертушка в первом экране (hero)
  dreamer.png          — вращающаяся пластинка в блоке Last release
audio/
  <Трек>.wav           — полные треки (исходники)
  samples/<Трек>.wav   — короткие 20-сек превью, которые играют на сайте по клику
```

## Аудио-превью треков
По клику на название трека или кнопку Play слева играет короткий семпл (~20 сек)
из `audio/samples/`. Это облегчённые нарезки (≈3.5 МБ вместо ~27 МБ), грузятся только
по клику; играет один трек за раз. Привязка — атрибут `data-src` у каждого `<li class="track">`.
Чтобы заменить превью: положите в `audio/samples/` файл с тем же именем, что у трека.
(Если хотите, можно отдавать полный трек — укажите в `data-src` путь к файлу из `audio/`.)

## Что и где менять (ищите пометки `<!-- EDIT -->` в index.html)
- **Ник артиста** — `<h1 class="hero__name">`.
- **Описание (пара строк)** — `<p class="hero__bio">`.
- **Название альбома** — `<h2 class="release__title">` и мета под ним.
- **Треки** — список `<ol class="tracklist">`; номера проставляются автоматически,
  просто добавляйте/удаляйте `<li class="track">` с названием и длительностью.
- **Ссылка на альбом** — `<a class="album-link" href="#">` — вставьте URL (Spotify/Apple…).
- **Соцсети** — блок `<nav class="social-row">`; подставьте реальные ссылки в `href`,
  лишние иконки удалите целиком (по одной `<a class="social">`).

## Заменить картинки
Положите свои файлы в `photos/` с теми же именами (`dreamer player.png`, `dreamer.png`)
или поменяйте пути в `index.html`. У пластинки лучше прозрачный фон (PNG).

## Цвета и шрифты
Всё настраивается в `styles.css`, блок `:root` в самом верху.
